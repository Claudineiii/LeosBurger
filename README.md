# LEOSBurger

Plataforma de pedidos online para lanchonete, com cardápio digital integrado.

## Status

Projeto iniciado em 27/09/2026.

## Stack

- TypeScript
- Node.js
- PostgreSQL
- Prisma
- Docker
- Vite
- Tailwind CSS
- daisyUI
- Flowbite
- Zod
- Vitest
